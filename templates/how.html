CineMatch uses a hybrid recommender system: two different ML models whose outputs are blended.

  • Real TMDB data → content model. Overviews, keywords, cast and genres feed the TF-IDF vectors.
  • TMDB average rating → quality signal used to generate realistic ratings and to rank popular movies for new users.
  • User ratings are simulated. TMDB does not publish per-user rating history, so 5 taste personas (sci-fi, family, crime, horror, feel-good) rate the real TMDB catalogue. Ratings from real users of this app are added and the model retrains automatically.

Model 1 · Content-Based Filtering (TF-IDF + Cosine Similarity)

  1. Each movie's genres, director and description are turned into text.
  2. TF-IDF converts the text into a number vector ({{ stats.vocab }} dimensions). Words that are rare across movies (e.g. "Horror") get more weight than common words.
  3. Your taste vector = sum of movie vectors, each multiplied by (your rating − your average rating). Movies you loved push the vector toward their features; movies you disliked push away.
  4. Cosine similarity between your taste vector and every unseen movie gives a content score.
cos(A, B) = (A · B) / (‖A‖ × ‖B‖)

✅ Works even for brand-new movies. ❌ Never suggests anything outside what you already like.

Model 2 · Collaborative Filtering (Matrix Factorization)

This is the supervised learning part. The model learns {{ stats.k }} hidden "taste factors" for every user and every movie (for example "likes sci-fi action" or "likes family animation") so that:

predicted_rating(u, m) = μ + b_user + b_movie + (user_factors · movie_factors)
  • μ = global average rating, b_user = how generous the user is, b_movie = how well-liked the movie is.
  • Training uses Stochastic Gradient Descent: for every known rating, compute the error and nudge the factors to reduce it, repeated for 80 epochs. L2 regularisation stops over-fitting.

✅ Finds surprising matches from users with similar taste. ❌ Needs enough ratings (cold-start problem).

Hybrid blend & cold start

final = w × collaborative + (1 − w) × content        w = 0.6 × min(1, your_ratings / 8)
  • 0 ratings → show popular movies (Bayesian average).
  • Few ratings → mostly content-based.
  • 8+ ratings → 60% collaborative + 40% content.

Every recommendation includes a plain-English reason, so the model is explainable.
