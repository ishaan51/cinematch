🎬 CineMatch – AI-Powered Movie Recommendation Platform

Discover movies you'll love with CineMatch!

CineMatch is an AI-powered movie recommendation platform that helps users discover movies based on their interests, ratings, and viewing history. It provides a personalized movie discovery experience with features like movie search, recommendations, ratings, reviews, watchlists, and an extensive movie catalogue powered by the TMDB API.

✨ Features

- 🔍 Movie Search: Search for movies and explore detailed information.
- 🤖 AI-Powered Recommendations: Get personalized movie suggestions based on your interests.
- ⭐ Ratings & Reviews: Rate movies and share your opinions.
- ❤️ Watchlist: Save your favourite movies to watch later.
- 🎥 Movie Catalogue: Explore a wide collection of movies.
- 👤 Personalized Experience: Discover movies based on your viewing preferences and history.
- 🌐 TMDB Integration: Fetch real-time movie information, posters, ratings, and details using the TMDB API.

⚙️ Installation & Setup

Follow these steps to run CineMatch locally.

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the project directory

cd CineMatch

3. Install dependencies

npm install

4. Configure environment variables

Create a ".env" file in the root directory and add your TMDB API key:

VITE_TMDB_API_KEY=your_tmdb_api_key

5. Start the development server

npm run dev

Open the local URL displayed in your terminal.

🔑 TMDB API

CineMatch uses the "TMDB API" (https://developer.themoviedb.org/) to retrieve movie information, posters, ratings, and other details.

Get your API key by creating an account on TMDB and configuring your API access.
